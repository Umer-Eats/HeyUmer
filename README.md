neuroscience.

## Edit the content

All of Umer's information (projects, programs, talks, awards, skills, coursework, links) is in
[`lib/data.js`](lib/data.js). Change it there and every page updates. The mission text is in
[`app/mission/page.js`](app/mission/page.js), and the character logo is in
[`components/Logo.js`](components/Logo.js).

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository. The defaults are correct.
3. Under **Settings → Environment Variables**, add the two variables below and redeploy.

| Variable | Value |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | The final address, e.g. `https://umerqureshi.com`. Used for canonical URLs, the sitemap and social cards. Without it the Vercel production URL is used. |
| `GOOGLE_SITE_VERIFICATION` | The verification code from Google Search Console (see below). |

## Search engine setup

The site is built to rank for searches such as "Umer Qureshi", "Umer Qureshi Florida",
"Umer Qureshi Pembroke Pines" and "Umer Qureshi awards". It includes:

- a unique title and description on every page, with his name and location
- canonical URLs, `robots.txt` and an automatic sitemap at `/sitemap.xml`
  (generated by [`app/sitemap.js`](app/sitemap.js))
- `Person` and `ProfilePage` structured data listing his location, awards and GitHub
- a social share image, and fully static pages that load fast on phones

Google only lists a site after it has found and crawled it, so do these once after deploying:

1. Open [Google Search Console](https://search.google.com/search-console) and add the site as
   a **URL prefix** property.
2. Choose the **HTML tag** method and copy the `content` value into the
   `GOOGLE_SITE_VERIFICATION` variable on Vercel. Redeploy, then press **Verify**.
3. Open **Sitemaps** and submit `sitemap.xml`.
4. Use **URL Inspection** on the home page and press **Request indexing**.
5. Link to the site from the GitHub profile, and from korah.app and coffee-house.app if
   possible. Links from sites Google already knows are what make it trust this one.

Indexing usually takes a few days to a couple of weeks. A custom domain with his name in it,
such as `umerqureshi.com`, helps a great deal.
